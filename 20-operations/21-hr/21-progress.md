### ⚠️ 배포 함정 — Dockerfile COPY 허용목록
루트 `.py`를 하나씩 나열하는 구조라 **새 모듈이 이미지에 안 들어갔다.**

### 2026-08-28 (2차) · 회사 직인 자동 날인 + 서명란 사전 생성 — 첫 실사용에서 드러난 결함 수정

**증상**: 편집기에서 서명 위치를 지정했는데 발송이 안 됨. 로그 확인 결과 **dispatch 요청 자체가 없었고**,

**내 구현 결함 2건**
1. 서명 필드 타입을 `signature`만 인정 → 실제로는 **도장(`stamp`)** 을 썼다. 한국 실무에선 도장이 표준인데 좁게 잡았다.
2. 서명 역할을 1개만 허용 → 실제로는 상대방·회사 **2개**를 만들었다.

**요구 추가**: 계약 회사(프로젝트렌트/필라멘트앤코)를 고르면 그 **직인이 자동으로 찍혀** 있어야 한다.

### 해결 — 서명란을 '만들게' 하지 않고 '옮기게' 한다
업로드 시 DocuSeal 템플릿에 **이름 붙은 서명란 2개를 미리 심는다**

직인 자산은 기존 `portal-v2/assets/seals/{project-rent,filament}.png` 재사용(RGBA 투명 PNG).

**필드에 이름이 필요한 이유**: DocuSeal은 필드를 **이름으로** 찾는다. 사용자가 편집기에서 직접 만든 필드는
이름이 비어 있고, `PUT /templates/{id}`로는 필드 이름을 못 붙인다(name/folder_name/roles/archived만 가능).
→ 이름이 없으면 원본 PDF로 **좌표를 그대로 옮겨 이름 붙은 템플릿을 재생성**하고 옛 템플릿은 아카이브한다

어제 넣은 **'시트 빈칸이면 xlsx 보존'(⑵) 규칙으로는 못 막는 케이스**였다.
`doc_status`는 시트에 미러되지 않는데(`update_status`는 '상태' 한 칸만) 시트에는
등록 시점 값이 **빈칸이 아니라 실값**으로 박혀 있다. 그래서 규칙 ⑵를 빠져나가고
8/21 22:50 export가 `candidate_input` → `candidate_registered`로 되돌렸다.

→ **xlsx가 SoT인 탭(onboarding·resignation·esign)을 export 대상에서 제외**(`_XLSX_SOT_PREFIXES`).
이 탭들은 도메인 store가 xlsx에 전 필드를 쓰므로 역방향 export 자체가 무의미하다.
어제 옵션 A(제외) 대신 B(병합)를 택했는데, B로는 '옛 실값' 덮어쓰기를 못 막는다.

**생존 확인** — PII·자가입력시각·국적·직종·부양가족수는 규칙 ⑵ 덕에 **전부 살아남았다**.
되돌아간 건 doc_status 하나뿐이었다.

### 2) doc_status 값이 시트의 '상태' 칸에 쓰이고 있었다
```python
status_value = updates.get("상태") or updates.get("doc_status", "")
sheets_sync.update_status("onboarding", no, status_value, ...)
```
doc_status만 갱신해도 그 값이 **사람이 읽는 한글 진행단계** 칸을 덮는다.
- 윤혜정 상태 `sign_completed` ← `tasks.py:73`이 doc_status만 갱신
- 하수민 상태 `candidate_input` ← 오늘 내가 doc_status 복구하다 재발시킴

→ `update_status(..., doc_status=)` 인자 추가, 각자 제 칸에 기록.
`status=None`이면 '상태' 칸은 건드리지 않는다. 빈 updates면 skip.

### 🐛 문서번호 중복 — 구조적 버그 (커밋 7e9b146, fly v361 배포)

**원인**: 운영이 `XLSX_MIRROR=false`라 **No는 Google Sheets가 발급**하는데, 문서번호는 갱신되지 않는 **로컬 xlsx의 `max_row`**로 미리 계산하고 있었다. xlsx에 쓰지 않으니 `max_row`가 고정 → 같은 번호 반복.
동시 요청 문제가 아니라 **설계 결함**. 배성원 2건도 `EMP-260708-0001`로 동일했다.

```python
# before — 갱신 안 되는 값으로 선계산
next_no = openpyxl.load_workbook(path).active.max_row
doc_no = _gen_doc_no("EMP", next_no, now)
no, row = append_to_xlsx(path, [..., doc_no, "대기"])
# after — append가 실제 발급한 No 사용
no, row = append_to_xlsx(path, [..., "", "대기"])
doc_no = _gen_doc_no("EMP", no, now)
row["문서번호"] = doc_no
_set_row_doc_no(path, no, doc_no)   # XLSX_MIRROR=true 환경 대비
```

기존 발급분(김가은·배성원)은 **소급 변경하지 않음** — 발송된 PDF 실물과 번호가 맞아야 한다.
