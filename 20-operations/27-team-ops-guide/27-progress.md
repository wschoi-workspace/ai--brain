## 2026-07-18 — 가이드 v1 작성 + 2부 규칙 ①~⑤ 대표 확정

### 문제의식 (Prologue)

- 장면 1 — "그 파일 어디 있어요?" "그거 지난번에 어떻게 하기로 했죠?" **조직에서 가장 비싼 자원은 대표와 시니어의 판단 시간인데, 그 시간이 '기억 검색'에 소모된다**
- 장면 2 — 노션·아마존(서면 내러티브)·깃랩(handbook-first)의 공통점: 개인의 기억을 조직의 기억으로 바꾸는 관행이 **시스템에 내장**돼 있다
- 장면 3 — "우리는 절반쯤 와 있다". ARISA가 있고 Reporting OS가 보고 품질을 잡았다
- 목적 문장 — "규칙이 없어서가 아니라, **규칙이 적혀 있지 않아서 생기는 비용**을 없애는 것"

### 1부 · 원리 8 (대표용)

각 원리마다 `왜 효율을 만드는가 → 프로젝트렌트 해석 → ARISA 현재 상태` 3단 대조 구조.

1. **공유의 기본값은 공개다** — 비공개가 예외 (ARISA: 브리프가 대표·팀장에게만 흐름 → 직원 상호 가시성 없음)
2. **찾을 수 있어야 공유다** — 검색 가능성이 곧 공유의 완성. "오래된 중복 문서는 없느니만 못하다"(Will Larson) (ARISA: 네이밍 시스템 검증 없음 → ID 매칭 정확도 직결)
3. **구조는 소수가 지키고, 입력은 모두가 한다** (ARISA: 이미 우위. 단 "누가 구조 관리자인가"가 미문서화)
4. ~8. — 템플릿·온보딩 / 오너 / 정리 리듬 / 문서→액션 / 정착 관찰
