### 핵심 개념

- **공유 vs 보고** — "공유는 알려주는 것, 보고는 판단하게 만드는 것." 보고인데 요청사항이 없으면 아직 보고가 아니다
- **Organizational Cognition Loop** — 업무 → Thinking → Reporting → Decision → Outcome → Learning → Knowledge. v1 범위는 **Thinking → Reporting → Decision** 구간
- **Report Score 100점** 자가채점 · **Thinking Cost**(대표 추가질문 수)

### 근거 데이터 (교육 논거)

2026 W26 실집계 — 주 **86건** 보고 / 완료율 75% / **열린 결정 2건** / **활동자 전원 decision_thinking 0점**.
"보고량은 충분하고 실행도 되고 있으나, 대표가 결정할 수 있게 올라온 것이 86건 중 2건뿐"이라는 문장이 이 프로젝트의 출발점이다.

### 하위호환 원칙

기존 구글시트(`1izuwjWPiJfbaJZ...`)의 **열 순서 변경 금지**, 확장은 우측 append만.
핵심업무 A~L + M`프로젝트` N`목표대비%` O`근거구분` P`★최중요` / 메타 A~J + K`ReportScore` L`ThinkingCost`.

### 검증

엑셀 수식 30개 참조 유효·배점 합 100·드롭다운 정상(LibreOffice 부재로 정적 검증) / HTML 22장 렌더·네비·오버플로·콘솔에러 0건(Playwright) / 3종 간 용어·배점·스키마 교차 일치 / 실명 잔존 0건.

## 2026-07-06 (같은 날 후속) — v1.1 봇 통합

`daily-report-bot.py`에 채점·질문 루프 구현.

- `SCORE_PROMPT`(루브릭 7항목, **"없음" 명시도 득점** — 공란과 구분)
- `rubric_evaluate` / `completion_evaluate` — 질문 큐 최대 3개, 규칙 안전망 유지
- `receive_completion` 3라운드 루프 ("없음"=답변 기록 / "패스"=건너뜀)
- 직원 회신(점수 + 다음 보완 한 줄) · 관리자 회신(헤더 점수, 폴백 시 "간이" 표기)
- 드라이런 3케이스 — 잘 쓴 보고 **98** / 부실 **20** / "없음" 명시 **95**. 변별력·상한·폴백 확인
- 교육가이드 용어 "대표" → **"관리자"** 변경 (실보고 인용 원문 2곳만 보존)

### 같은 날 · 회귀 복구와 조사 2건

- **회귀 복구** — 최초 scp 배포가 맥미니 전용 하드닝 커밋 2개(유실방지 P0~P3, 대화영속화·to_thread)를 덮어쓴 것을 발견 → `git merge-file` 3-way 병합(충돌 4곳 수동 해소)으로 재배포. 메타 시트 열 최종 **M=submitted_at / N=ReportScore / O=score_detail / P=ThinkingCost(예약)**
