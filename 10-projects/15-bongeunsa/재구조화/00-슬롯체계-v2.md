# 봉은사 재구조화 — 슬롯 체계 v2 (2026-07-29, 10-STEP 구조 반영)

> v1(8슬롯)에서 **10-STEP Master Strategy 구조**로 확장. 기존 503개 요소는 전량 재사용하며 슬롯만 재배치·추가한다.
> v1 슬롯 ID는 **그대로 유지**한다(재태깅 비용 0). 추가 슬롯만 새로 판다.

## 보고서의 핵심 질문
> **"봉은문화센터는 미래의 불교와 사회를 연결하는 어떤 플랫폼이 되어야 하는가?"**

## 확정된 구조 원칙 (2026-07-29 대표 확정)
1. **정신문화 거점 = Option A(문화 목적지)에 병합.** 별도 옵션으로 두지 않는다.
2. **A·B·C는 타임라인 연계형이 아니다.** 3-Track(20~30 → 46~65 → 70~92억)을 세 안에 걸쳐 계단으로 쓰지 않는다.
   → **각 안은 독립 완결된 컨셉**이며, 각자의 최적 타겟·서비스·BM·공간·수익구조·로드맵을 갖는다.
   → 로드맵은 "A→B→C 순서"가 아니라 **선택된 안 내부의 단계**로만 존재한다.
3. **STEP 5는 시설이 아니라 서비스·BM으로 분류**한다.
4. 결론을 정해놓고 리서치를 맞추지 않는다. 동일 기준 재구성 → A·B·C가 자연히 도출 → 동일 기준 평가.

**각 선택축은 5축으로 분석한다**: 장점 · 단점 · 리스크 · 기회 · 영향도

**종속관계 (STEP 3에서 명시할 것)**
- `C6`(브랜드↔산업화)이 `C3`(합법↔제도개선)을 사실상 종속시킨다 — 산업화하려면 제도를 건드려야 한다
- `C1`(프리미엄↔대중화)과 `C5`(지역↔글로벌)는 강한 상관
- → **상위 결정 2개(C6, C1)** + 파생 4개로 정리한다. 6개를 대등하게 나열하면 64조합이 된다

### STEP 6 — 서비스 라이브러리
`S6-RAW`에 전량 나열 후 `S6-G1`~`S6-Gn`으로 그루핑.

**각 service 요소는 5축 평가를 갖는다** (v1의 `viability`를 대체·확장):
```jsonc
"eval": {
  "revenue":       "H|M|L",   // 수익성
  "brand":         "H|M|L",   // 브랜드 효과
  "difficulty":    "H|M|L",   // 운영 난이도 (H=어려움)
  "legal":         "Tier1|Tier2|Tier3",  // 법률
  "sustainability":"H|M|L"    // 지속가능성
},
"viability": { "C1":[...], "C2":[...], "C5":[...], "C6":[...] }  // 어느 선택 아래 살아남는가
```

**같은 서비스의 변주를 별개 요소로 만든다** — 대관 하나도 매스형·프리미엄형·멤버십형이 각각 다른 서비스이고 평가가 다르다.
