# 봉은사 사용자 인식 RXR 리서치 (R02) — 실행 브리프

너는 봉은문화센터 활용전략 프로젝트의 리서치를 수행한다. 이 작업의 목적은 **봉은사 방문 경험의 1차 데이터를 처음으로 확보하는 것**이다.

지금까지 이 프로젝트의 방문객·이용자 근거는 **전부 2차 인용**이었다 — 나무위키, 언론 기사, 논문. 직접 수집한 방문 후기는 0건이다. 이번 실행이 그 공백을 메운다.

작업 디렉토리: `~/do-better-workspace`

## STEP 1 — 크롤링

```bash
cd ~/do-better-workspace/80-r-tech/84-scripts/bongeunsa
python3 bongeunsa_crawl.py --days 1095 > /tmp/rxr-crawl.log 2>&1
```

- `--days 1095` = 3년
- 설정은 `10-projects/15-bongeunsa/rxr/config.json` 이 SSOT다. **여기 없는 값을 임의로 만들지 마라**
- 산출: `10-projects/15-bongeunsa/rxr/data/{오늘날짜}/` 아래 `naver-raw.json`, `naver-enriched.json`, `summary.json`

### ★ 크롤 직후 반드시 할 것 — 노이즈 검증

봉은사는 **"봉은사로", "봉은사역"이 강남 상권 주소로 널리 쓰인다.** 필터를 걸어뒀지만 뚫릴 수 있다. 실제로 개발 중 1차 테스트에서 16건 중 11건이 노이즈로 통과한 적이 있다(한국어 부분문자열 충돌: `기도`←"여기도", `절에`←"계절에", `주지`←"주지 않다").

```
필터 통과분에서 무작위 50건의 제목을 뽑아 육안으로 확인하라.
맛집·부동산·헬스장·오피스텔 글이 5% 이상 섞여 있으면 STOP.
config의 temple_context_keywords·noise_exclusion을 고치고 다시 크롤한다.
```

이 검증을 건너뛰지 마라. 현대차 캐빈에어 프로젝트에서 광고 노이즈 6,279건을 분석 후에 발견해 전면 재작업한 전례가 있다.

### 함께 확인할 것
- `summary.json`의 **연도별 분포** — 3년에 고르게 퍼졌는가. 특정 연도가 0건이면 sim 정렬 편중이므로 쿼리를 보강한다
- **본문 확보율** — `naver-enriched.json`에서 본문이 실제로 붙은 비율. 50% 미만이면 이후 분석 신뢰도를 낮춰 서술한다

## STEP 3 — RXR 5단 구조로 해석

단순 집계가 아니다. 수집한 후기를 아래 다섯 단계로 정리한다.

1. **Fact** — 사람들이 실제로 쓴 말. 원문 인용을 반드시 포함하라
2. **Insight** — 왜 그런 반응이 나왔는가
3. **Hidden Need** — 겉으로 드러나지 않은 욕구. 말하지 않았지만 행동에 드러난 것
4. **Experience Opportunity** — 봉은사가 제공할 수 있는 새로운 경험
5. **Business Opportunity** — 수익 모델·콘텐츠·서비스·공간·굿즈·멤버십·교육·행사

### 반드시 답해야 할 질문

**왜 오는가** — 산책인가 기도인가 관광인가 사진인가 데이트인가 명상인가
**언제 오는가** — 계절·요일·시간대. 국화축제·연등회 같은 행사 의존도는 얼마나 되는가
**누구와 오는가** — 혼자·가족·연인·친구·외국인 동반 (추정)
**무엇이 좋았는가** — 다시 오는 이유. 기억에 남은 것
**무엇이 아쉬웠는가** — 개선 요청. 없어서 아쉬웠던 것
**강남 주민에게 봉은사는 무엇인가** — 공원인가 쉼터인가 문화공간인가 종교시설인가

마지막 질문이 이 프로젝트의 핵심이다. 봉은문화센터를 어떤 공간으로 재정의할지가 여기 걸려 있다.
