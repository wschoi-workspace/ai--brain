## 2026-09-05 전수 검증에서 고친 것

발표 전 렌더·산술·SSOT 전수 점검에서 실제 오류 5건이 나와 수정했습니다.

| # | 무엇이 틀렸나 | 조치 |
|---|---|---|
| 1 | **요약본 푸터 페이지 번호** — 60장 중 59장이 `/ 57`로 남아 있고 25장부터 번호가 3씩 밀림(마지막이 `57 / 57`) | 60장 전량 `NN / 60`으로 재번호 |
| 2 | **요약본 24·34장이 푸터를 침범** — V2 신규 3장 중 2장에서 본문 마지막 줄이 푸터와 겹쳐 잘림 | 24장 행 여백 축소·34장 `xtight` 적용. 60장 전량 푸터 침범 0 재확인 |
| 3 | **본편 구(舊) 임대료 오기 3곳** — `93,194원 · GBD 68.4%`. 실제 계산은 2.5억 ÷ 2,687.3평 = `93,030원 · 68.3%`이고 원장(E-1113)도 같은 값 | 세 곳 정정. 정정 후 값(133,323원·97.9~110.5%)은 원래 정확 |
| 4 | **근거칩 E-1110~1115가 shards에 없었음** — `elements.json`에만 있어 다음 `merge_validate.py` 실행에 6건이 사라질 상태. polarity 5건이 스키마 위반(`positive/negative`), 슬롯 1건 미정의(`S9-BASE`) | `shards/15-area-correction.json`으로 편입 + 스키마 정규화. `merge_validate.py` 오류 0·경고 0 |
| 5 | **PPTX 추출기가 활성 슬라이드 1장만 측정** — 나머지 59장 좌표가 전부 0. 카드·구분선 도형이 통째로 누락되던 상태 | `00-system/02-scripts/html-deck-extract-layout.js`가 슬라이드별로 활성화 후 측정하도록 수정 |

**SSOT 보강** — 요약본에만 있고 본편에 없던 **공간 귀속 집계표(105.0억 = A 75.8 + B 29.2 · 매출의 28%가 전용면적 0)** 를 본편 부록 A에 편입했습니다. 부록 A 13라인 표와 같은 숫자를 공간 귀속으로 다시 자른 것이고, PART 5에서 교차참조합니다.

## 아직 확정되지 않은 것

대외 발표 전에 알고 있어야 할 미확인 항목입니다.

1. **공조실 실면적** — 약 210㎡는 가정치. 실측되면 사용 면적이 확정됩니다
2. **1층 주차장** — 계약서가 1층에 열거했는데 바닥면적 3,477.75 안에 있는지 미확인. 있으면 1층 가용이 줄어듭니다
3. **용적률 10.9%** — 실측 지상 연면적(8,217.99㎡ = 12.4%)과 여전히 999㎡ 어긋납니다
4. **유권해석 5건** — 미제출 (문체부 4문항 + 다원 전용)
5. **재임대 실제 보수액** — 27억이냐 57.5억이냐. 증분 판단의 갈림
6. **벤치마크 12슬롯** — 공통 운영비·전시 실단가·다이닝 회전 등 재무 입력값 대기
7. **지하1층 실측** — 3,744㎡는 ★☆☆ 개산(±5~10%). 봉안 2,000기안은 하단에서도 성립하지만 증설 판단에는 실측이 필요합니다
