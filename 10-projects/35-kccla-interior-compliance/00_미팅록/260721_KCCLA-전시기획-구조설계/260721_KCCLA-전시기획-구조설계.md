## [1] 프로젝트 개요 / 배경

LA 한국문화원(KCCLA) 리뉴얼 사업. 대상 공간은 **한국문화원**과 **코리아센터** 2개.

유니원이 사업 낙찰 주관사로, 원래 문화원 측 7천만원 + 자체 3천만원 = 총 1억 집행 계획이었으나 문화원 측에서 예산을 축소 중이다. 현재 태원 본부장님과 4천 확보까지 합의한 상태.

문화원 측은 이 사업이 자기 메인 성과가 아니라 예산을 아끼려는 경향이 있다. 반면 원장님은 2년 뒤 문체부 복귀가 목표로, **국내 언론 노출**을 핵심 성과로 보고 있다.

## [2] Summary

LA 한국문화원(KCCLA) 전시·운영 구조를 재설계한 기획 회의. 기존 콘텐츠 나열식 구성을 **시간축 기반 블록 구조**로 전환 — 9월 패션(개막 한정) → 10월 한글·텍스트힙 → 11월~ 라이프스타일·서울슈퍼마켓. **한국문화원**은 도슨트 기반 슬로우 모드, **코리아센터**는 이벤트 기반 드라이브 구조로 분리 운영. 디지털 체험 기기(5천만원) 예산의 콘텐츠 전용 가능성 확인. 예산 축소 대응으로 8월 초 예산 착수 필수, 법인·리테일 라이센스 리스크 체크 등 실행 과제 도출. 차주 초 워크숍에서 마스터플랜 확정 목표.

| 키 | 값 |
|---|---|
| 공간 | 한국문화원(상설) + 코리아센터(이벤트) |
| 전체 기간 | 2026년 9월 ~ 2027년 상반기 (추정) |
| 가용 예산 | 콘텐츠 예산 재배분 기반 (총 규모 미확정) |
| 주관사 | 유니원 (사업 낙찰) |
| 시공 | 원장님 지시로 진행 확정 |

## [3] 본문 — 기획 6카테고리

### A. 방향성/디렉션 (WHY)

- 한국문화원: "웬만하면 마음대로 하세요" 분위기 — 예산을 줄이는 대신 자율성을 확보
- 코리아센터: 단기 이벤트 베이스로 운영, 북적거림 유지가 원장님의 핵심 기대
- 전체 지향점: 콘텐츠가 계속 순환하며 뉴스거리를 만드는 구조

### B. 프로젝트 골/핵심 요구 (WHAT)

**시간축 블록 구조 확정**

| 시기 | 테마 | 공간 |
|---|---|---|
| 9월~10월 초 | 패션 + 개막식 | 코리아센터 (패션쇼는 개막 한정) |
| 10월 (한글날·한복의날·한지의날 연계) | 한글/텍스트힙 + 독립출판·웹툰 | 한국문화원 → 코리아센터로 확장 |
| 11월~연말 | 라이프스타일 + 푸드 + 서울슈퍼마켓(세일즈 연계) | — |
| 12월 | 한지 (유네스코 등재 기념일 연계) | 후반 배치 |

- 한국문화원: 도슨트 1명 상설 교대, 느긋한 체험·설명 슬로우 구조
- 코리아센터: 금토일 집중 인력 배치, 평일은 뮤트/슬로우 모드

### C. 경쟁/포지셔닝 (WHERE)

- [검토] LA 현지 한국문화 관련 경쟁 공간·이벤트와의 차별화 필요
- 기존 레퍼런스: 유니원의 과거 해외 마케팅 실행 사례 공유 요청됨

### D. 실행 가능성 (CAN)

1. **디지털 체험 기기**: 삼성 AI 기기 포함 소프트웨어 5개 = 5천만원 배정. 현재 "섬처럼 떠다니는" 상태. 뷰티 슬롯 없음 → 체험 콘텐츠로 전용 가능
2. **인력**: 현지 매니저 1명 상시 배치 확정. 추가 1명은 디지털 체험 예산 전용 시 가능
3. **가용 콘텐츠 소싱처**
   - 공진원(한국공예디자인문화진흥원): 한복·라이프스타일 지원
   - 항공 박물관: 패션 관련
   - 국중박 문화재단(뮤츠 라인): 전통문화 상품 IP → 판매 연계 고려
   - 한국관광공사: "원장님이 시켰어요"로 콘텐츠 협조 필수 확보 가능
4. **외부 확장**: 멜로즈 팝업 1건 협조 확보 (커피/티 + 한국 작가 제품)
5. **법인/리테일**: 유니원 미국 법인으로 리테일 라이센스 가능 여부 → 상무님 확인 필요. 푸드 라이센스도 별도 확인
6. **LA 파트너**
   - GFFG 미국 론칭 시 행정처리 지원한 인물 (레퓨테이션 리스크 낮음)
   - 갤러리스트 네트워크 통한 지인 소개 인물

### E. 실행 방안 (HOW)

1. **예산 재배분**: 프로젝트 베이스로 기본 가용 콘텐츠 + 유니원 릴레이션 가용 + 이해관계자(기업/관공서) 지원 3층 구조로 정리
2. **드라이브 콘텐츠**: 블록 전환 시점마다 이벤트 설계 (예: 삼양 체험행사, 한식 원데이 클래스, 코리아 위크 등)
3. **마케팅 구조**
   - 오프닝: 보도자료 + 온라인 볼륨 초반 뿌리기
   - 메인: 블록 전환 시점(10월~11월)에 메이저 언론 기획기사 타겟
   - 한국 미디어 핸들링: 특파원 활용 vs 에어프레미아 태워서 기자 직접 데려오기 비교 검토
   - 프로젝트렌트 자체 마케팅 툴 미국 창 리셋 진행 중
4. **예산 집행 일정**: 50% 선집행 → 오프닝 시 대부분 소진 → 즉시 20% 추가 신청. 8월 초 예산 미동 시 10월 오픈 불가
5. **시공**: "원장님이 시켰다"로 진행. 외벽은 도색까지만 합의, 꾸미기는 내년 예산으로 유도

### F. 리스크/기회 (IF)

1. **유니원 직접 결제 주체 리스크**: 사업 낙찰 주관사가 직접 장사(리테일)하면 국정감사 리스크 → 제3자 파트너 또는 별도 법인 검토 필요
2. **LA 현지 파트너 리스크**: 대표님 과거 부정적 경험으로 현지 파트너 끼우기 부담 → 레퓨테이션 검증된 2인 후보 확보
3. **물류 비용**: 왕복 관세 포함 최소 5천~8천, 집기 제작·배송 1.5~2억, 공사비 3~4억 → 총 3억 이상 선소진 후 콘텐츠 예산 투입
4. **인건비 부담**: 코리아센터 상설 인력 최소 2명 필요 시 주중 운영 비용 증가
5. [검토] 원장님의 '북적거림' 기대와 예산 제약 사이 갭이 프로젝트 전반의 핵심 리스크
