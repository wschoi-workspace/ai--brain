## 원문 대비 보강한 것 (제안서의 실제 가치)
1. **"위탁 = 재고 부담 최소화"의 모호함 해소** — 위탁 시 미판매 재고는 백화점에서 **공급자(OF)로 이동**할 뿐 사라지지 않는다. 비교표에 `재고 리스크 귀속`·`초기 자금 부담`·`적합한 시점` 행을 분리해 명시
2. **역산 일정 신설** — 원문엔 "11월 중순"만 있고 일정이 없었다. 15주 역산 간트 작성, **작가 확정 마지노선 8월 말**, 최대 리스크 구간 = 라이선스 협의(빨간 바)로 표기
3. **"왜 OF인가" 신설** — 원문에 경쟁 우위 기술이 없었다. 답십리 고미술상가 원천 접근성 + 한영석 청명주 에디션 번역 이력 + End-to-End 실행
4. **시시호시 갭 논리** — 취급 4개 카테고리(뷰티·인테리어 소품·패션 잡화·문구류)에 아트 축이 없음 → "새 카테고리가 아니라 **인테리어 소품 × 문구류의 교차점**"으로 프레이밍해 MD 진입 장벽 낮춤
5. **권장안 = 단계 전환** — 1차 위탁 검증 → 2차 선매입. 근거: 신규 카테고리에 판매 데이터 없음 + **'월간 시시호시' 팝업이 이미 검증 경로로 존재**
6. **미확정 수치를 TBD로 명시** — 추정치로 채우지 않고 협의 항목 + 결정 주체 + 시한으로 전환

## 핵심 리서치 결과 (상세: `research-notes.md`)
- **방한객 1,894만명**(2025), 2019년 대비 108.2% — 한국관광공사
- **구매 1건당 15만원(2019) → 12만원(2025)**, 1인당 총소비 +83%, **구매 횟수 +124%** — 한국관광공사 데이터랩 카드결제 분석
  → 목표 소비자가 "15만원 미만"이 이 구간과 정확히 맞물린다는 근거
- **가챠샵 +142% / 문구점 +48.7% / 서점 +39.9%** (2025.1~9 결제 건수)
  → 작고·가볍고·취향 담긴 물건이 팔린다. 아트 프린트가 이 조건에 부합
- **미술시장 6,382억원**(2025), 2022년 정점 대비 **−20.9%** — 예술경영지원센터
  → 투자재 미술은 위축, 그러나 15만원 미만 프린트는 다른 시장. **역풍이 아니라 배경**으로 재해석
- **시시호시**: 전국 6개 점포, 2030세대 매출 **45%**, 330여 브랜드, 취급 = 뷰티·인테리어 소품·패션 잡화·문구류, **'월간 시시호시'** 2~3주 팝업 플랫폼 운영
